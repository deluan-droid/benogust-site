## 🎨 Paleta de Cores

### Cores Principais
- **Roxo Principal**: `#7D3CED` (RGB: 125, 60, 237)
- **Preto**: `#1A1A1A` (RGB: 26, 26, 26)
- **Cinza Escuro**: `#3E3E3E` (RGB: 62, 62, 62)
- **Cinza Claro**: `#E5E7EB` (RGB: 229, 231, 235)

### Cores Secundárias
- **Roxo Vibrante** (gradiente): `#8B5CF6` a `#A78BFA`
- **Branco**: `#FFFFFF` (RGB: 255, 255, 255)
- **Preto com Transparência**: rgba(0, 0, 0, 0.8)

### Uso das Cores
- **Roxo**: Elemento principal, destaque, CTAs, headings
- **Preto**: Textos, background, estrutura
- **Cinza**: Textos secundários, borders, divisores
- **Branco**: Backgrounds, textos em fundos escuros

## 🔤 Tipografia

### Fonte Principal
**Montserrat**
- **Pesos**: Bold, SemiBold, Regular, Light
- **Uso**: Headings, títulos, logos
- **Espaçamento**: Ajustado para leitura clara

### Fonte Secundária
**Montserrat** (Regular/Medium)
- **Uso**: Body text, parágrafos, conteúdo

### Hierarquia de Texto
```
H1 (Headings): Montserrat Bold, 48px, Roxo Principal
H2 (Subheadings): Montserrat SemiBold, 36px, Roxo Principal
H3: Montserrat SemiBold, 24px, Preto
Paragraph: Montserrat Regular, 16px, Preto
Small: Montserrat Regular, 14px, Cinza Escuro
```

## 🎬 Efeitos Visuais

### Gradientes Recomendados
```
Gradiente Roxo: #7D3CED → #A78BFA
Gradiente Escuro: #1A1A1A → #3E3E3E
Gradiente Misto: #7D3CED → #1A1A1A (diagonal)
```

### Efeitos de Luz (Glow)
- **Roxo Glow**: Sombra em roxo com blur para destaque
- **Efeito Neon**: Linhas roxo fluorescente (como no ID Visual)

### Transições
- Duração padrão: 0.3s
- Timing: ease-in-out
- Hover effects: aumento de brilho ou sombra
